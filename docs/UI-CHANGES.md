# Operator interface

The operator can upload a phone photograph, use live capture on a secure origin, or open a local video and capture a frame. Selecting media resets the confirmation. An active submission remains guarded even if the operator changes confirmation or media. Live HTTP on a private LAN supports uploads and local video files. Browser camera permission requires a secure origin.

The result explicitly renders PASS, FAIL or UNKNOWN. Advisory states are PENDING, COMPLETED, FALLBACK, ERROR and TIMEOUT. Selecting a new result cancels the old poll and discards any stale responses. The result shows vision forward time, server time through deterministic verdict (including inference wait), advisory queue wait, and Llama process execution. The device header reports interface link state.

Daily counts use all stored rows in the browser’s local day. History displays at most 50 records and JSON export contains the full history. See [release handoff](PHASE1-RELEASE.md) for the Pi run and the remaining interactive checks.
